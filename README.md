# Student Score Analyzer

Script Python sử dụng `pandas` để kiểm tra tính hợp lệ của dữ liệu điểm sinh viên (`math`, `python`, `english`), tính điểm trung bình, xếp loại học lực và xuất báo cáo thống kê.

## Cấu trúc thư mục

```text
student-analyzer/
├── data/               # Chứa file CSV dữ liệu điểm đầu vào
├── src/                # Mã nguồn xử lý dữ liệu
├── output/             # Thư mục chứa các file báo cáo được xuất ra
└── .gitignore
